# GOLO — Glamorous Outfit & Luxurious Outlook

GOLO is a premium, full-stack luxury e-commerce platform designed for a sophisticated shopping experience.

## ✨ Implemented Features

### 🛍️ E-Commerce Core
- **Advanced Product Browsing:** Category filtering, live search, and multi-criteria sorting (Price, Newest, Featured).
- **Luxury Detail Page:** High-resolution galleries, variant selection, and detailed specifications.
- **Persistent Cart:** A slide-in cart drawer that persists between sessions with real-time total calculations.
- **Wishlist System:** One-click "Save to Wishlist" with heart animations, persistent for logged-in users.
- **Secure Checkout:** Multi-step checkout with address management and order summary.

### 🤖 AI-Powered Assistant
- **Concierge Chatbot:** A customized AI assistant (Gemini 1.5 Flash) trained to provide luxury customer service, product recommendations, and policy information.

### 🛡️ Secure Backend
- **Full-Stack Express Server:** Custom API built with Node.js and Express.
- **SQL Database (SQLite):** Robust relational schema with 15 tables handling users, orders, products, and more.
- **JWT Authentication:** Secure login/register with token-based authorization and "Me" session persistence.
- **Admin Command Centre:** A secure area for administrators to view revenue stats, manage orders, and monitor system health.

### 🎨 Design & Experience
- **Luxury Aesthetic:** A refined Obsidian/Gold/Ivory color palette inspired by premium fashion houses.
- **Theme Switching:** Seamless transition between Light and Dark modes.
- **Responsive Mastery:** Optimized for Desktop, Tablet, and Mobile (specifically tested for 375px precision).
- **Animations:** Smooth route transitions, hover effects, and marquee announcements for a "living" brand feel.
- **Performance:** Integrated skeleton loaders and lazy-loaded components for near-instant perceived load times.
